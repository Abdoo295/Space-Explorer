# 🚀 Space Explorer

An interactive space exploration website that lets you explore planets, upcoming space launches, and NASA's Astronomy Picture of the Day.

## ✨ Features

- 🌍 Explore detailed information about planets
- 🚀 View upcoming space launches
- 🌌 Browse NASA's Astronomy Picture of the Day
- 📊 Compare planets using dynamic data
- 📱 Fully responsive design

## 🛠️ Technologies

- HTML5
- Tailwind CSS
- JavaScript
- REST APIs
- Font Awesome

## 🔌 APIs

- NASA APOD API
- The Space Devs API
- Solar System OpenData API
